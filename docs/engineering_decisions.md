# Engineering Decisions

1. Use PostgreSQL as the relational database.
2. Use RESTful APIs.
3. Use service objects for business logic.
4. Use RSpec and follow TDD.
5. Use database indexes for frequently queried columns.
6. Use SQL aggregation for salary statistics.
7. Use bulk insertion for employee seeding.
8. Use pagination for employee listing.
9. Store salary using decimal precision.
10. Compare salaries only within the same currency.
